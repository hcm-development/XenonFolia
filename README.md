- Tối ưu hệ thống tạo chunks
- Tối ưu/làm lại hệ thống xray
- Bukkit Region / Bukkit Scheduler support as Bukkit Api plugin
- Optimized Spawning System

---

## 📦 Tải về & Build
- **Tải bản phát hành:** [Releases](https://github.com/Khoasoma/XenonFolia/releases)
- **Tự build:**
    1. Cài đặt JDK 21
    2. Chạy lệnh sau trong thư mục dự án:
    ```shell
    ./gradlew applyPatches && ./gradlew createMojmapPaperclipJar
    ```
    3. File jar sẽ nằm ở `xenonfolia-server/build/libs/`
